# Tester checklist

Thanks for trying Speed Timer. This takes about 5 minutes.

**Link:** https://rohitboora05.github.io/timer/

## 1. Open it

- [ ] Scan the QR code or open the link (Safari on iPhone/iPad, Chrome on Android).
- [ ] The timer screen appears with scroll wheels and Cancel / Start buttons.

## 2. Basic timer

- [ ] Set 0 hours, 1 min, 0 sec and tap **Start**. The ring drains and the time counts down.
- [ ] Tap **Pause**, then **Resume**. The time carries on from where it stopped.
- [ ] Tap **Cancel**. The wheels come back.

## 3. Hidden speed panel

- [ ] Triple-tap the top-right corner. The Speed panel opens.
- [ ] Enter **Pass 8 h 0 m in 4 s**, tap **Set**, then **Done**.
- [ ] Set the wheels to 8 hours and tap **Start**. It should reach 00:00:00.00 in about 4 seconds.
- [ ] Nothing from the panel is left on screen after **Done**.

## 4. Install and full screen

- [ ] Add it to the Home Screen (iPhone/iPad: Share → Add to Home Screen; Android: ⋮ → Install app).
- [ ] Open it from the Home Screen. No browser toolbar is visible.
- [ ] Start a long timer and don't touch the device for 2 minutes. The screen stays on.
- [ ] Turn on Airplane Mode and open it from the Home Screen again. It still loads.

## 5. Record

- [ ] Screen-record a 10-second run at high speed.

## Please send back

- Device model and OS version (iPhone/iPad: Settings → General → About; Android: Settings → About phone)
- The screen recording
- Anything that looked wrong or didn't work, with the step number
